# Downarr — Plan

Native SwiftUI macOS app to manage a local Sonarr / Radarr / Jellyfin / NZBGet stack.
Personal use only, never distributed.

## 1. Target environment (verified 2026-09-15)

| Service  | Endpoint                  | Auth                    | Version   | Scale               |
|----------|---------------------------|-------------------------|-----------|---------------------|
| Sonarr   | http://192.168.50.131:8989 | `X-Api-Key` header      | 4.0.19    | 689 series          |
| Radarr   | http://192.168.50.131:7878 | `X-Api-Key` header      | 6.3.0     | 492 movies          |
| Jellyfin | http://192.168.50.131:8345 | MediaBrowser token      | 12.0.0    | 1557 films / 684 shows / 37840 eps |
| NZBGet   | http://192.168.50.131:6789 | HTTP Basic              | 26.2      | queue + 28 history  |
| Deluge   | http://192.168.50.131:8112 | password-only, cookie   | 2.2.0     | 23 torrents         |

Root folders: Sonarr `/mnt/tv`, Radarr `/mnt/movies` (4.5 TB free).
Quality profiles (both apps share ids): 1 Any, 2 SD, 3 HD-720p, 4 HD-1080p, 5 Ultra-HD, 6 HD-720p/1080p.
Jellyfin libraries: Movies, Shows, HFR Shows, Music, Christmas Music, Playlists.

## 2. Tech decisions

- **Xcode project generated by XcodeGen** (`project.yml`) so the whole thing rebuilds from source
  with `./build.sh`; no hand-edited `.pbxproj`.
- **SwiftUI + Observation-free `ObservableObject`** stores, one per service, injected as
  `@EnvironmentObject`. Swift 5 language mode (`SWIFT_VERSION = 5.0`) deliberately — Swift 6 strict
  concurrency buys nothing here and costs a lot of build friction.
- **macOS 14.0 deployment target**, builds/runs on the machine's macOS 26.6.
- **No sandbox** (needs plain-HTTP LAN access), `NSAllowsArbitraryLoads`, plus
  `NSLocalNetworkUsageDescription` for the Sequoia+ local-network prompt.
- **Config in UserDefaults**, not Keychain. Ad-hoc signing changes the code identity on every
  rebuild, which makes Keychain ACLs prompt or fail; for a single-user local app that never leaves
  the machine, a plist is the pragmatic store. Settings UI can edit every field.
- **Custom async image pipeline** (`ImageLoader`) with in-memory NSCache + on-disk cache in
  Application Support. `AsyncImage` is not viable for a 689-poster grid.
- **Every list is `LazyVGrid`/`List` over pre-filtered arrays**; filtering/sorting happens in the
  store, not in the view body.

## 4. Feature scope per service

### Sonarr
- Series library: poster grid + list toggle, live search, filters (monitored / missing / ended /
  continuing), sort (title, added, size, % complete, next airing), per-series completion bar.
- Series detail: fanart header, stats, overview, per-season accordion with episode tables, monitor
  toggles (series / season / episode), file quality + size per episode.
- Actions: automatic season/episode search, **interactive search** (`/release?episodeId=` →
  grab), refresh, rescan disk, rename, edit (profile, path, monitored, series type, season folder),
  delete (with optional file deletion).
- Add series: `/series/lookup` search → poster results → root folder, quality profile, monitor
  strategy, season folder, search-on-add.
- Calendar (shared with Radarr), Wanted/Missing with per-item search, History.

### Radarr
Same surface adapted to movies: library grid, detail with file info, availability + minimum
availability, automatic + interactive search (`/release?movieId=`), edit, delete, `/movie/lookup`
add flow, calendar, wanted/missing, history.

### Jellyfin (management only, no playback)
- Auth via `AuthenticateByName`, token persisted; re-auth on 401.
- Library browser: virtual folders + item grid with paging (`/Items?userId=…&StartIndex=`),
  filters by type, sort, search. Series → seasons → episodes drill-down via `/Shows/{id}/Seasons`
  and `/Shows/{id}/Episodes`.
- **Metadata editor**: name, original title, sort name, overview, taglines, dates, year, ratings,
  official rating, genres, studios, tags, provider ids (Imdb/Tmdb/Tvdb), plus `LockData` and
  per-field `LockedFields`. Saves with `POST /Items/{id}`.
- **Fix match / identify**: `POST /Items/RemoteSearch/{Movie|Series|Episode|…}` with manual
  name/year/provider-id overrides, result cards with poster, apply via
  `/Items/RemoteSearch/Apply/{id}?replaceAllImages=`.
- **Images**: current images (`/Items/{id}/Images`) with delete; browse remote artwork
  (`/Items/{id}/RemoteImages`) filtered by type/provider/language with rating + resolution; set one
  via `RemoteImages/Download`; upload a local file (base64 `POST /Items/{id}/Images/{type}`).
- Refresh metadata per item with the four refresh modes; library scan; scheduled-task trigger.

### Deluge
- JSON-RPC over `/json` with a password-only login and a `_session_id` cookie; re-login and retry
  automatically when the session lapses.
- Torrent list with progress, state, ratio, seeds/peers, tracker, label; filter by state/label,
  eight sort keys, search.
- Per-torrent and bulk: pause/resume, queue moves, force recheck, speed cap, relabel, remove with
  or without data. Session: pause-all, global up/down limits, config and label/tracker breakdowns.
- Add by magnet or `.torrent` URL with label, download location and add-paused.

### NZBGet
- JSON-RPC over `/jsonrpc` + Basic auth. Status header (rate, remaining, free disk, uptime,
  paused state, article cache), live-ish polling.
- Queue: per-group progress, category, priority, health, post-processing stage. Actions: pause /
  resume / delete (with files) / move top-bottom-up-down / set priority / set category.
- Global: pause/resume download + post + scan, speed limit presets, reload/shutdown guarded.
- History with status decoding (SUCCESS/UNPACK, PAR failures), retry / mark / delete.
- Add NZB by URL (`append` RPC) with category and priority.

## 5. Cross-cutting

- **Dashboard**: service health tiles (reachable, version, latency), disk free, counts, active
  downloads with progress, next-up calendar strip, recently added from Jellyfin, warnings from
  `/health` on both *arrs.
- **Activity**: single table merging Sonarr + Radarr queues with the download client actually
  working on them — the NZBGet group (matched on release name, since NZBGet does not echo the
  *arr's download id) or the Deluge torrent (matched on infohash, which is exactly what the *arrs
  report) — so a stuck import is visible in one place.
- **Polling**: 5 s while the Activity/Downloads/Dashboard tab is visible, paused otherwise; every
  other screen is pull-to-refresh + on-appear.
- **Errors** surface as a non-blocking banner with the failing request, never a fatal alert.

## 6. Build & run

```sh
./build.sh          # xcodegen + xcodebuild -configuration Release, opens Downarr.app
open Downarr.xcodeproj
```

Artifacts land in `build/`. `docs/API-NOTES.md` records the exact endpoint shapes probed from the
live servers so future work doesn't have to re-derive them.
